# Project Overview

The goal of _Design System_ project is to provide

> a flexible framework of standards, reusable components, and documentation to create a minimal and adaptable UI

## Files and folders

All .html files in the root folder are generated, for instance the [homepage](./index.html)

List of folders:

- [css/](../css/): stylesheets that implement the design system styling.
- [doc/](../doc/): documentation in _Markdown format_ including principles, guidelines and instructions.
- [html/](../html/): contains HTML pages and snippets.
- [assets/](../assets/): logo and other assets.
- [page/](../page/): HTML pages generated by `npm run generate_pages` script.
- [script/](../script/): npm scripts related files.
